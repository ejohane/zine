# Zine Next web

The web PWA is Erik's experimental channel; native iOS remains the mainstream
production direction. Recreate the native build-4 mock closely, including its
real development metadata and illustrative /v1 capability fixtures. No production
authentication, account data mutation, ingestion, AI or media playback in this pass.

Use on an open Duo/iPad in landscape, desktop, and compact phone widths. Installable
standalone shell; locally durable edits; offline access to all bundled content.
